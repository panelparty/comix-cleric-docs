# Comix Cleric Documentation

The official documentation package for Comix Cleric.

---

## Contributing

> [!WARNING]
> Contributions are not yet opened as we prepare ourselves and the codebase to accept them.

To get started, have `git` or GitHub Desktop installed and clone this repo to your local machine.

There is currently no provided way to preview outputs, as this package is not a self-contained application.
You may choose to use another tool, like a previewer built into your IDE or a tool like [Obsidian](https://obsidian.md/).

Create new files as-needed, but be sure your additions or alterations do not fit into another file or section first.

Be sure to follow standard Markdown conventions, and generally give a single new line between blocks.

Only add dividing lines between major, unrelated sections.

Formatting example:
```md
# Document Title

Document subtitle

---

## Section One

Details about section one.

### Sub-section

Details about the sub-section.

---

## Section Two

...
```
