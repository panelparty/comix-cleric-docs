# Pricing & Plans <!-- order: 3 -->

Here's everything you need to know about our pricing page!

---



### Pricing

Our pricing is based on the lowest amount we can currently offer for each service tier. We try to keep the app slim so it keeps costs down for us and you.

> [!NOTE]
> It is possible that if we get enough support, either via our hosting plans or Ko-fi support, we can open up a proper ***free tier*** so anyone can host a Comix Cleric site with us, regardless of their ability to pay.


##### Free

There is no cost, because is technically not a plan. We just want to make you aware that Comix Cleric is, first and foremost, an open-source application that you can run on your own hardware!



##### Basic - $5/mo

This tier automatically sets-up and deploys a fresh, fully-featured Comix Cleric app!
No release features are restricted, except using a custom domain name.
- An instance of the Comix Cleric app.
- Complimentary subdomain of your choice. (Example: `my-comic.comixcleric.com`)
- Shared server hosting. (Your app will share a server with other creators)

Server specs: 0.5 CPU | 512MB RAM | 10GB storage



##### Standard - $10/mo

This tier includes everything in the Basic tier, plus:
- Use a custom domain name.
- \*Early access to upcoming features.

-# \**Basically gives you optional access to future features once they are considered stable enough for release.*

Server specs: 1 CPU | 1GB RAM | 20GB storage



##### Advanced - $20/mo

This tier includes everything offered in the Basic and Advanced tiers, plus:
- Exclusive color themes, crafted by Grawlich himself!
- \*Even ***earlier*** access to in-development features in our beta branch!
- Vote on up-coming features to see what makes it to the top of the priority list!

Server specs: 2 CPU | 2GB RAM | 40GB storage



##### Custom

This tier can include any combination of feature sets you like! We can't put a price on it, since that price will vary depending on what services you choose. This price can vary wildly depending on your wants and needs, but your price is fixed until you add more to your plan.

This tier offers bonus options (we must manually set these up):
- Dedicated server hosting. (A server all to yourself)
- Custom features/conmponents for your app.
- Bespoke themes and layouts.

Min server specs: 2 CPU | 2GB RAM | 80GB storage

### Can't Afford Hosting?

If you're already a member of our hosting plans, you can reach out to us and request to take part in the Creator Fund, a small pool of cash that is used to keep beloved comic sites alive.

We want to be able to keep every comic hosted with us around for as long as we can, but right now we simply cannot afford to host everyone for free. Hopefully some day we can offer a proper free tier like other platforms!
