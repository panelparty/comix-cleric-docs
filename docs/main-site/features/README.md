## Features

This is a large (but, not all-inclusive) list of the features that are currently completed, being testing, in-progress, or planned.

#### Completed Features

Are features that are currently considered stable and ready for use by everyone!

#### Testing Features

Are features present in the beta branches and are actively undergoing stability testing.

#### In-Progress Features

Are features that are actively being worked-on, but are not yet stable enough for testing.

#### Planned Features

Are features that we plan to add into the app some day in the near future.

If you feel we aren't moving fast enough on some of these, feel free to take-up the reigns and contribute your own version! You might just get it added-in early for all to enjoy!
