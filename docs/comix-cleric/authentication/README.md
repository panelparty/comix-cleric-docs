# Login & Registration <!-- order: 1 -->

Learn how to create and manage your account!

---


### Register a New Account

To create an account, locate a registration form. A button is typically located in the bottom left corner of your browser window.

> [!WARNING]
> If you are unable to locate a registration form, it's possible that we have temporarily disabled the ability to register new accounts.

Click the button to open the form. If the form defaults to "Login", locate a text-only button near the bottom of the pop-up window that will allow you to switch to registration.


###### Avatar

-# *Optional*

An image displayed on your profile as your main visual identity.

-# Must be an image: PNG, JPG/JPEG, SVG, GIF, WEBP, or AVIF. File size limit is 5MB.

> [!IMPORTANT]
> Our system automatically resizes and reformats the image you provide to something more optimal for us to display. Your original image is not retained, so make sure you didn't submit your only copy!

> [!IMPORTANT]
> In the interest of user safety and security, we intentionally strip any image metadata that could be used to identify an image source.


###### Email

-# *Required*

The main method of verifying your account. It must be a valid email address.

-# Maximum 64 characters.

> [!NOTE]
> Example: `user@example.com`


###### Displayname

-# *Optional*

A cosmetic name to be displayed in-place of you Username. It may contain spaces and special characters.

-# Minimum 3 characters, maximum 32 characters.

> [!NOTE]
> Example: `Massive Dave: The Sequel`

> [!NOTE]
> Arbitrary HTML/Markdown is not allowed. The text provided is not rendered by our systems and will only be displayed as it is provided to us.


###### Username

-# *Required*

Your main, unique identifier. This is similar to a "handle" on other platforms. It is the main way other users can find you.

As stated, this value **must** be unique. There should be a visual indicator that displays the validity of the provided username. It checks for valid formatting, as well as if the name is already in-use.

-# Minimum 3 characters, maximum 24 characters. May only contain uppercase/lowercase characters, numbers, and periods.

> [!NOTE]
> Example: `massivedave2.0`


###### Password - ***Required***

-# Minimum 8 characters, maximum 64 characters. Must contain at least: one uppercase and lowercase character, one number, and one special character *\!\@\#\$\%\^\&\**

> [!NOTE]
> Example: `Abcd1234!`


###### Re-type Password - ***Required***

Same as the previous field, but it must also match the previous field exactly.
