# First-time Setup <!-- order: 2 -->

This page contains information about setting up your Comix Cleric app for the first time!

---

> [!NOTE]
> If you are using our hosting plans, you should receive an email with instructions on setting up your new site! Simply follow the link, fill in a few details, and you're good to go!


### Setup

You can locate your setup page by adding `/api/setup` to your site URL in the addressbar.

The end result should look something like: `https://my-app.comixcleric.com/api/setup`

> [!TIP]
> We are always working to improve the user experience in this app. Things may look/work slightly different by launch!

Here, you will be asked to fill-in a few details to create your local account. This account differs from your Comix Cleric hub site account. This account is a local admin account that gives you full access to modify and update your site appearance and create posts.
