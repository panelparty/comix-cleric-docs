# First-time Setup <!-- order: 2 -->

This page contains information about setting up your Comix Cleric app for the first time!

---

## New Site Setup

> [!NOTE]
> If you are using our hosting plans, you should receive an email with instructions on setting up your new site! Simply follow the link, fill in a few details, and you're good to go!

You can locate your setup page by adding `/api/setup` to your site URL in the addressbar.

The end result should look something like: `https://my-app.comixcleric.com/api/setup`

Here, you will be asked to fill-in a few details to create your local account. This account differs from your Comix Cleric hub site account. This account is a local admin account that gives you full access to modify and update your site appearance and create posts.

> [!IMPORTANT]
> This setup method may be changing to automatically run and provide you with default credentials.

###### Email

-# *Required*

The main method of verifying your account. It must be a valid email address.

-# Maximum 64 characters.

> Example: `user@example.com`

###### Displayname

-# *Optional*

A cosmetic name to be displayed in-place of you Username. It may contain spaces and special characters.

-# Minimum 3 characters, maximum 32 characters.

> Example: `Massive Dave: The Sequel`

> [!NOTE]
> Arbitrary HTML/Markdown is not allowed. The text provided is not rendered by our systems and will only be displayed as it is provided to us.

###### Username

-# *Required; Unique*

Your main, unique identifier. This is similar to a "handle" on other platforms. It is the main way other users can find you.

-# Minimum 3 characters, maximum 24 characters. May only contain uppercase/lowercase characters, numbers, and periods.

> Example: `massivedave2.0`

###### Password

-# *Required*

-# Minimum 8 characters, maximum 64 characters. Must contain at least: one uppercase and lowercase character, one number, and one special character *\!\@\#\$\%\^\&\**

> Example: `Abcd1234!`

###### Re-type Password

-# *Required*

Same as the previous field, but it must also match the previous field exactly.
