# Media Management <!-- order: 6 -->

Learn to manage images, videos, and files within Comix Cleric!

---

### Adding New Media

Adding files to Comix Cleric is incredibly simple!

Just open your admin dashboard, navigate over to a post (or the Media Management section itself) and locate an "Upload Files" button. You can click on this button to open a small dialog that will allow you to click to select files from your device, or drag and drop them in from another window.

Once added, the list should refresh to show you the new entries *(if your list is already sorted by recent)*.

---

### Managing Existing Media

If you've already got files uploaded, but want to edit the title, filename, etc. you can access file editing in the Media Management page.

Simply find and click on the media file you would like to edit, this should take you to the editing page. Once there, you can modify several properties about your media files:

> [!IMPORTANT]
> We will eventually provide in-place editing, file replacement, and batch editing tools.

###### Title

A custom cosmetic name for your image. Used as alt-text if no other description is provided.

###### Filename Download

A custom name for the media file.
