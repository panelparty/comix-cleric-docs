# Security <!-- order: 99 -->

Important info about handling vulnerabilities!

---

### Supported Versions

Due to team size, and therefore a tight schedule, security updates and patches are only applied to the latest release at this time. If you feel an older version is worthy of patching, please submit a contribution/PR of your changes for an LTS (long-term support) release of that app version.

> [!NOTE]
> LTS versions are primarily handled by the community to preserve versions of the app they prefer using.

---

### Vulnerability Reporting

If you have discovered a security vulnerability in this project, please report it to us privately. ***Do not disclose it as a public issue.*** This gives us time to work with you to fix the issue before public exposure, reducing the chance that the exploit will be used before a patch is released.

Please send any vulnerability disclosures directly to Panel Party staff via email at [helloworld@panelparty.net](mailto:helloworld@panelparty.net). This project is maintained by a small team of core developers & volunteers. As such, please give us at least <u>**90 days**</u> to work on a fix before public exposure.
