### Dynamic Data Tags

These tags are simple text/strings that our system reads in select locations to display data that changes over time. This makes it much easier to set certain fields yourself without manually updating code!



##### Our current set:



`$CURRENT_YEAR`

Inserts the current year, stays in-sync.



`$APP_NAME`

Inserts your app name, set in **Global Settings**.



`$APP_SUBTITLE`

Inserts your app subtitle, set in **Global Settings**.



`$SERIES_NAME`

Inserts your series name, set in **Series <i class="ph-bold ph-arrow-left"></i> Edit**.



`$BSKY_LINK`

Inserts a link to your Bluesky profile. `https://bsky.app/profile/` + `Bluesky Handle` set in **Global Settings**.
